# AssetFlow - Enterprise Asset & Resource Management System

## Odoo Hackathon 2026

AssetFlow is a web-based ERP platform designed to help organizations manage their physical assets and shared resources efficiently. The system provides centralized asset tracking, allocation, maintenance workflows, resource booking, and analytics through a role-based interface.

## Features

- User Authentication & Role-Based Access Control
- Asset Registration & Tracking
- Asset Allocation & Transfer
- Resource Booking
- Maintenance Request Workflow
- Dashboard & Reports
- Notifications

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB
